# MATRIX-ZYGISK v0.4 — Changelog

## Milestone focus

Create a trustworthy foundation for future integration without pretending a runtime connection exists.

### Added
- Versioned runtime contract schema and conservative validation.
- Explicit connection state vocabulary: `disconnected`, `connecting`, `connected`, `unsupported`, `error`, and `stale`.
- Simulation-only provider with no network or privileged operations.
- Architecture, security, feature matrix, and manual test guidance.
- Node-based contract invariant checks.

### Preserved
- Static GitHub Pages deployment from `webui/`.
- Independent crimson/black MATRIX visual identity.
- Explicit disconnected and prototype labels.

### Not included
- Android companion application.
- Root or runtime API.
- ADB or shell command execution.
- Live device data, writes, module installation, or upstream binary synchronization.
- Any claim of Zygisk Next integration or compatibility.
